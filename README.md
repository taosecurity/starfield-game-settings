# Starfield Game Settings

Every setting Starfield knows about, with its built-in default value: the game settings (`GMST`) you change with `setgs`, the INI settings you change with `setini` or an INI file, and the extra ones only the Creation Kit uses. Read from the game itself (game version 1.16.244.0).

**View it here:** https://taosecurity.github.io/starfield-game-settings/

- About 6,775 game settings: 6,575 built into `Starfield.exe`, plus 200 that exist only as records in `Starfield.esm`. Where `Starfield.esm` has a record, its value and FormID are shown too, and the 1,215 records that change the built-in default are marked.
- About 4,800 INI settings, each with its section (`fFPWorldFOV:Camera`), and about 3,700 settings only the Creation Kit defines.
- Search, filters for kind, value type, category and "Changed by Starfield.esm", and click-to-copy console commands (`getgs` / `getini`).
- Short explanations of the kinds of settings, how to read the names, settings worth trying, how mods change game settings, and a few fossils from earlier Bethesda games.

Made by Richard Bejtlich of [Richard Presents Starfield Essentials](https://www.youtube.com/@RichardBejtlich).

## Notes

- This is an unofficial list, not made or endorsed by Bethesda. Starfield is a trademark of ZeniMax Media.
- Only setting names, kinds and values are shown, no game code.
- The default is the value built into the game. INI files, the in-game options and mods can change it.
- The list is regenerated after game updates.

Also see [Starfield Record Types](https://taosecurity.github.io/starfield-record-types/), [Starfield Console Commands](https://taosecurity.github.io/starfield-console-commands/), [Starfield Locations](https://taosecurity.github.io/starfield-locations/) and [Starfield Item IDs](https://taosecurity.github.io/starfield-item-ids/).
